# Household fault experiment: results

Results of the experiment specified in `house_faults.md` (same directory): every arm drives
the same 64 routes over eight household layouts with stock Nav2 MPPI (`loose_path`, oracle
map); each robot suffers one fault from the eight representative faults at a place on its
route, is not told, keeps replanning, and is measured over the 3 s after the fault. Fault-free
runs of the same arms give the efficiency.

- With faults: 4 seeds x 64 robots x 8 layouts = 2,048 faults per arm, paired across arms by
  (layout, seed, robot): the same fault at the same place.
- Fault-free: 2 seeds x 64 robots x 8 layouts = 1,024 robots per arm, 60 s limit.
- Hopper jobs: 3309194 (normal, ours w0.5, w1), 3312724 (ours w3, w4), 3312725 (inflation
  baselines), 3312726 and 3312727 (fault-free), November 2026; code at commit 4c94101.
- Raw runs: `/scratch/mnguy21/failbench/mppi/{house_faults,house_clean}/<arm>/`; local
  copies and the report JSONs in `benchmark_results/failbench/` (not tracked).
- Regenerate: `uv run python -m failbench.scripts.house_report --root <house_faults> --out report`
  and `uv run python -m failbench.scripts.house_clean_report --root <house_clean> --out eff`,
  then `uv run python -m failbench.scripts.house_tables --faults report.json --clean eff.json`.

Arms: `normal` is stock MPPI (critic weight 0); `ours_w<k>` adds the risk critic at weight k;
`inflate_<m>` adds m metres to the local costmap's inflation around every obstacle;
`semantic_<m>` scales that margin by severity (m at glass, 2m at people, 0.32m at furniture,
0.16m at walls). Every arm tracks the same global path; only the local planner differs.

## Notes for the paper

- Ours lowers every collision and damage metric with faults, monotonically up to weight 3,
  at a fault-free slowdown of 4% (w0.5), 11% (w1) and 37% (w3). Weight 4 is no safer than 3
  (paired w4 - w3: collisions +0.5 ± 0.6 points, damage +0.01 ± 0.13) and slower with lower
  success: safety saturates at weight 3.
- Falls are unchanged (about 21% for every arm): the critic does not prevent the fault's fall,
  it changes what the robot falls into.
- Ours avoids contact rather than softening it: robots that do touch hit at about 0.6 m/s
  in every arm.
- Local-costmap inflation, uniform or by severity, barely moves the robot (within 0.5 m of a
  person fault-free stays at about 40%) and does not lower collisions; larger margins raise
  contacts and path error. The MPPI cost critic (weight 3.81) is weak against the path terms,
  so inflation shifts cost without shifting the path much.
- Planning time is for a batch of 64 robots on one A100 (about 37 ms per robot for ours); a
  single-robot timing is still to be measured for the real-time claim.
- Pending: the reactive CBF safety filter baseline (`cbf_0.1`, `cbf_0.2`; jobs 3321145 and
  3321146).
